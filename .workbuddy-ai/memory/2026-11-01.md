# 2026-11-01

## Perbaikan alur "tidak sampai ke aplikasi Kinerja" (ReviewASN)

**Gejala:** `ReviewASN.exe --all` login sukses, tapi berhenti di
`https://smartasn.jabarprov.go.id/dashboard` dengan error
`tidak sampai ke aplikasi Kinerja. Tab yang ada: [.../dashboard]`.

**Akar masalah (hasil diagnosa `--probe` ke situs live):**
1. `klikCardKinerja()` mencari elemen berteks PERSIS "Kinerja" → yang kena
   selalu `<button>Kinerja</button>` di navbar (cuma buka dropdown), bukan
   kartu layanan di "Layanan Unggulan" yang teksnya "Kinerja Kinerja Pegawai".
2. Akibatnya modal "Pilih Tahun Kinerja" tidak pernah muncul.
3. `pilihTahun()` juga salah: radio-nya berlabel "Tahun 2026", bukan "2026",
   jadi pencarian teks persis `TAHUN` tidak pernah kena.

**Alur yang benar (terverifikasi):**
dashboard → klik kartu "Kinerja Pegawai" → modal radio `input[name=tahun]`
→ klik "Lanjutkan ke Kinerja" → tab smartasn pindah ke
`/framer/kinerja?tahun=2026` → otomatis buka TAB BARU ke
`kinerja.jabarprov.go.id/kinerjajabar/autologin?username=...&anotationKey=...&authenticatorKey=...`
(bukan lewat `window.open` yang bisa ditangkap JS).

**Perubahan kode (main.go):**
- `klikCardKinerja()`: JS `jsKlikKartuKinerja`, pilih elemen TERKECIL yang
  memuat "Kinerja Pegawai", abaikan `header/nav`, retry sampai 20 detik
  (dashboard Vue butuh waktu render).
- `pilihTahun()`: tunggu `input[name='tahun']`, klik radio via value, lalu
  klik tombol berisi "Lanjutkan". Return bool.
- `urlHalaman()` / `halamanHidup()`: pembungkus panic-safe untuk
  `MustInfo()` (Chrome mengganti target saat navigasi lintas-origin SSO,
  handle lama bisa mati → panic "No target with given id found").
  Dipakai di `satuAkun()` setelah login dan di seluruh `bukaKinerja()`.

**Telegram "Conflict: terminated by other getUpdates request":**
- Penyebab: dua instance ReviewASN jalan bersamaan (masing-masing polling).
- `single.go`: file kontrol `quit` sekarang hanya dipantau oleh proses yang
  MEMEGANG lock; file kontrol basi dihapus saat start; kalau lock tetap tidak
  didapat setelah 20 detik → `os.Exit(1)` dengan pesan jelas (dulu lanjut saja).
- `telegram.go`: ganti `GetUpdatesChan` (yang spam log) dengan polling manual
  + `galatKonflik()` + backoff 10 detik + `tungguTelegramBebas()` saat start.

**Verifikasi:** `--cek-alur` (mode baru, read-only) → login OK, masuk Kinerja
11 detik, halaman Review Perilaku terbaca 25 kartu (semua "Sudah Direview").
`--all` start bersih: web UI 2323 + bot aktif tanpa conflict.

**Mode debug baru:** `--cek-alur` (uji alur tanpa menyimpan review),
`--probe` (dump DOM dashboard ke `probe_*.json`).
